# SeatsConnect sports tickets

Home page for SeatsConnect sports tickets and matchday hospitality. The look follows the SeatsConnect site. The fixtures follow the public sports catalogue: Premier League, European football, Liverpool, Celtic, rugby, NFL London, Wimbledon, and Formula 1.

## Run it on your computer

You need Node.js 20 or newer. Check with `node -v`.

On Windows, in PowerShell:

```powershell
cd C:\Users\Gulab\Desktop
git clone <your-repo-url> seatsconnect-sports
cd seatsconnect-sports
npm install
npm run dev
```

Then open http://localhost:3000

`npm run build` then `npm start` runs the production build.

## On this page

- Search and filter fixtures, including European football, Liverpool, and Celtic
- Prices in USD, EUR, GBP, and CHF
- Ticket, hospitality, and ticket-and-hotel requests
- Group quotes and gift vouchers
- Sign-in kept on this page
- The Seats Circle
